Partagez des images médicales avec vos patients

📊 Suivi des messages

Suivez le statut de tous vos messages WhatsApp

⚡ Interface simple

Interface similaire à l'envoi d'emails dans Odoo

Vos données et clés API sont stockées de manière sécurisée

🌍 Format international

Support de tous les numéros de téléphone au format E.164

Comment ça marche ?

  1. Créez un compte sur WasenderApi.com
  2. Scannez le QR code avec WhatsApp
  3. Copiez votre clé API
  4. Configurez Odoo avec votre clé API
  5. C'est prêt ! Envoyez vos ordonnances par WhatsApp

Configuration requise

  • Odoo 19.0 ou supérieur
  • Module acs_hms installé
  • Compte WasenderApi actif
  • Bibliothèque Python requests

Utilisation

Une fois configuré, l'utilisation est très simple :

  1. Ouvrez une ordonnance confirmée
  2. Cliquez sur "Send via WhatsApp"
  3. Vérifiez le numéro de téléphone
  4. Personnalisez le message si nécessaire
  5. Cliquez sur "Send"

Le patient recevra l'ordonnance directement sur son WhatsApp !
